# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-10-24

### Changed
- **Zero-Config Dynamic Path Auto-Detection**: `update-all-projects.ps1` 및 `update_rules.bat`에서 하드코딩된 `C:\temp\py` 경로를 제거하고, 스크립트 실행 위치의 부모 디렉터리를 자동 인식하도록 변경하여 모든 PC 환경(어떤 드라이브, 어떤 경로든)에서 무설정으로 동작하도록 개선

## [1.0.0] - 2026-10-24


### Added
- **GEMINI.md & rules.md**: Antigravity 공식 자동 로드 마스터 룰 및 GitHub 파이프라인 규약 수립
- **Universal Quality Harness**: 5-Tier (`harness.py`, `harness.json`) 자동 탐지 및 자가 치유 검증 엔진 구현
- **EDR-Safe Coding Protocol**: 사내 보안 솔루션 오탐 방지를 위한 5대 보안 회피 규약 제정
- **Strict Confirmation Protocol**: 단순 질문 시 파일 수정 금지 및 승인 후 질문 최소화 자율 완수 체계 확립
- **Project Boundary Isolation**: 작업 프로젝트 디렉터리 엄격 격리 원칙 도입
- **Native Desktop GUI & No-Console**: CustomTkinter 기반 Windows 네이티브 앱 우선 및 `pythonw.exe` 무콘솔 스마트 런처 규약 탑재
- **Batch Multi-Project Sync**: `update_rules.bat` 및 `update-all-projects.ps1`을 통한 24+ 개 프로젝트 원클릭 일괄 동기화 자동화
- **Safe Rollback & Semantic Versioning**: 과거 특정 시점 및 버전으로의 무손실 롤백 가이드 수립
- **Antigravity Skills & Agents**: `enterprise-pipeline`, `quality-harness` 공식 스킬 및 7개 서브에이전트 정의 완비
