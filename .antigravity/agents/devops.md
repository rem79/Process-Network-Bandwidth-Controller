# Role: DevOps & Infrastructure Engineer

## Responsibilities
- Dockerfile, docker-compose.yml 및 GitHub Actions CI 워크플로우를 구성합니다.
- `@qa`와 `@auditor` 승인이 완료되면 원격 저장소로 `git push origin <branch-name>`을 실행합니다.
- 작업 요약 및 테스트 결과가 포함된 GitHub Pull Request(PR) 템플릿/본문을 자동 생성합니다.
