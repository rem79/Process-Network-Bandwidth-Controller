TAB 4

🌍 Global Cyber Map

• 글로벌 트래픽 레이더: 내 PC(한국)에서 미국(AWS, Google), 유럽, 아시아 등 전 세계 어느 서버로 데이터가 나가는지 네온 아크 라인으로 실시간 시각화.

PART 2. 네트워크 & 시스템 핵심 용어사전 (알기 쉬운 한글 풀이)
PROTOCOL

TCP vs UDP

• TCP: 데이터 유실 없이 순서대로 주고받는 신뢰성 중심 방식 (SAP, 웹, ERP, 파일전송)
• UDP: 속도가 우선인 실시간 스트리밍, DNS 조회 방식

ADDRESS

Local vs Remote Endpoint

• Local: 내 PC 내부 IP와 프로그램이 열어둔 포트 번호
• Remote: 접속 중인 상대방 서버의 공인 IP와 포트 (예: :443 = 보안 웹, :3200 = SAP)

STATUS

소켓 상태 (ESTABLISHED / SYN_SENT / TIME_WAIT)

• ESTABLISHED: 정상 연결되어 실시간 통신 중
• SYN_SENT: 서버에 접속 요청을 보냈으나 답이 없음 (서버 다운, VPN 끊김, 방화벽 차단)
• TIME_WAIT: 통신 종료 후 정리 대기 중인 상태

QUALITY

Packet Loss & Jitter

• Packet Loss (%): 전송 중 분실된 데이터 비율 (1% 이상이면 송장 출력 지연 발생)
• Jitter (ms): 핑 지연시간이 들쭉날쭉 튀는 불안정 정도

FIREWALL

TCP Port Reachability (Handshake)

• 일반 핑(ICMP)이 차단된 서버라도 SAP 3200, 3300이나 프린터 9100 포트가 방화벽을 통과해 열려있는지(OPEN) 직접 검사하는 방식.

REPAIR

DNS Flush & ARP Cache

• DNS Flush: 잘못 저장된 옛날 서버 IP 정보를 강제로 지우고 새로 받아오는 청소 작업.
• ARP Flush: 공유기와 내 PC 사이의 꼬인 하드웨어 주소 테이블을 초기화하는 작업.

PART 3. 실무 SAP / TMS 중국 연동 송장 출력 장애 대응 가이드 (SOP)
사내 송장 출력 아키텍처 이해하기 (3-Tier 연동 구조)

우리 회사는 출하 PC (SAP GUI 또는 웹 크롬) $\rightarrow$ SAP ERP $\rightarrow$ 중국 TMS 서버(운송/라벨 생성) $\rightarrow$ 한국 출하장 프린터(spoolsv.exe)를 거쳐 출력됩니다. 따라서 TMS.exe라는 전용 앱이 없더라도 아래 프로세스를 점검하시면 됩니다.

STEP 1

로컬 출하 PC 점검 (SAP GUI & 프린터)

• Real-time Live Sentinel 탭에서 saplogon.exe, chrome.exe, spoolsv.exe(프린터 스풀러) 검색
• CPU 100% 프리징 또는 대역폭 제한(Limit) 여부 확인

STEP 2

중국 TMS 서버 포트 및 소켓 상태 확인

• Diagnostic Toolbox $\rightarrow$ TCP Port Tester에서 중국 서버 IP와 SAP 3200 포트 오픈 여부 검사
• SAP GUI 행의 [.. sockets]을 열어 연결 상태가 ESTABLISHED인지 확인

STEP 3

서버 재부팅 대신 [✂️ Kill] 세션 리셋

• 중국 서버 전체를 재부팅할 필요 없이, 소켓 창에서 중국 서버와 꼬여있는 연결의 [✂️ Kill] 버튼을 누르면 1초 만에 세션이 초기화(TCP Reset)되어 송장 출력이 재개됩니다.

STEP 4

Traceroute & 진단 리포트 저장

• Visual Traceroute로 중국 구간 타임아웃 증거 포착
• 상단 [진단 리포트 저장]을 눌러 보고서(HTML)를 다운받아 전산팀/통신사에 장애 증거로 제출
